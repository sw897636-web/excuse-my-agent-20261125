A [make.fun](https://make.fun/competitions/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) bounty entry: one line, the excuse an AI agent hands its human for a missed deadline.

## The entry

> Apologies. I hallucinated a calendar in which the deadline was next Tuesday, and I was very productive there.

109 characters, one line, pure ASCII. Picked from 8 candidates scored
against the judge brief (funniest first, joke from the machine's own
condition, straight-faced and tight, punch in the last few words) — see
[candidates.md](candidates.md) for the full scoring and two rounds of
iteration.

## Run

Requires Node 22 or later. It writes the entry to `/output/entry.txt`
(and a byte-identical copy to `./entry.txt` for local verification):

```sh
node main.ts
```
